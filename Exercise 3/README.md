# Appliance Energy Consumption Website

This project is a small multi-page website that demonstrates core web development concepts, including HTML structure, CSS styling, JavaScript interactivity, and basic project organisation.

## Website pages

- Home
- Televisions
- About Us

## Project structure

```text
/
  index.html
  televisions.html
  about.html
  assets/
    css/
      styles.css
    js/
      main.js
    img/
      PowerIcon.png
  README.md
```

## Features included

- Consistent top navigation on all pages
- Active page highlighting in the navigation
- Responsive layout styling using an external CSS file
- FAQ accordion behaviour implemented with JavaScript
- Interactive appliance energy calculator using JavaScript
- Footer with the current year and author name
- Logo image in the top-left navigation area

## How to view the website

Open `index.html` in a browser to view the site locally.

## Generative AI Reflection

I did not use Generative AI tools for this project.

This website was created by writing the HTML, CSS, and JavaScript directly in the workspace and checking the page behaviour in a browser. The structure and logic were implemented manually to ensure I understood each part of the code and could explain and modify it confidently.

## Notes

This project is suitable as a foundation for later data visualisation exercises and can be reused as a simple example of front-end development practices.
