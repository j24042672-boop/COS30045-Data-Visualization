About this project

Why this website exists

This demonstration site was created to explore how digital tools can help people understand energy use in household appliances. By presenting simple examples and calculations, we can make otherwise technical information easier to interpret.

The site demonstrates key web development concepts, including structured page layout, consistent styling, interactive JavaScript, and user-focused design.

Learning focus

  • Use HTML to structure clear and accessible content.
  • Apply CSS for a consistent visual style across the website.
  • Use JavaScript to enhance the page with interactive elements.
  • Organise a small multi-page project with clean file structure.
